# Changelog

## 0.2.1 - 2026-07-15

- Reject UUID strings with misplaced hyphens.
- Add tests for parsing, formatting, seeded generation, versions, variants,
  ordering, equality, and hashing.
- Add CI on Linux and Windows.

## 0.2.0

- Implement `Eq`, `Hash`, `Ord`, and `ToString`.
- Add nil, max, simple, URN, comparison, and hash helpers.

## 0.1.0

- Add UUID v1, v4, and v7 generation.
- Add canonical and bare UUID parsing.
